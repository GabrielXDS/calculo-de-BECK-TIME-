# Calculadora de Backtime — Tribal Wars

Script JavaScript criado como ferramenta auxiliar para **Tribal Wars**. A calculadora recebe a duração de um ataque e o horário de chegada informado pelo usuário e calcula o horário estimado de retorno da tropa.

## Como funciona

O script solicita:

1. duração do ataque no formato `HH:MM:SS`;
2. horário de chegada no formato `HH:MM:SS`.

Em seguida soma a duração ao horário de chegada e exibe o horário de retorno calculado.

## Uso

O código pode ser executado no navegador como JavaScript/bookmarklet durante estudos e testes pessoais.

Arquivo principal: `calculadoraBT.js`.

## Objetivo

Projeto pequeno criado para praticar manipulação de horários, funções JavaScript e automação de uma tarefa repetitiva dentro de um contexto de jogo.

> Projeto independente, sem vínculo oficial com Tribal Wars ou seus desenvolvedores.
